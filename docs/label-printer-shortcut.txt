== BCWEB label-printing Chrome shortcuts: FNSKU labels (Dymo — Goods In, AMZ Shipment) and Royal Mail labels (Zebra — Customer Orders, at the bottom)

Without this shortcut every label pops up Chrome's print dialog. With it, labels go straight to the default printer.

-- Shortcut target (paste into "Target" when creating the shortcut):

"C:\Program Files\Google\Chrome\Application\chrome.exe" --kiosk-printing --user-data-dir="C:\bcweb-chrome" https://bcweb.vercel.app

Name it e.g. "BCWEB (labels)".

-- Notes
- If Chrome is installed elsewhere, check the path: right-click your normal Chrome shortcut > Properties > Target.
  (Sometimes it is "C:\Program Files (x86)\Google\Chrome\Application\chrome.exe".)
- --user-data-dir gives this shortcut its own Chrome profile, so your normal Chrome keeps the print dialog. Log in to BCWEB once in it.
- Close ALL Chrome windows before first use if you leave --user-data-dir off, or the flag is ignored.
- --kiosk-printing sends EVERYTHING printed from this window to the Windows default printer, so:
    1. Install the label printer's Windows driver.
    2. Make the label printer the Windows default printer.
    3. In the Dymo's Printing Preferences set the paper to the label roll: a 54 mm long size to match the labels on the roll
       (25 x 54 mm - 11352 / 30336 "1 x 2-1/8 in"), orientation PORTRAIT. NOT 30252 Address: that's 89 mm long and the label
       prints ~17 mm along, cut off. The page is sent portrait with the label drawn sideways (the preview looks sideways - right).
    4. Still in the Dymo's Printing Preferences > Advanced: Print Quality = "Barcodes and Graphics" (NOT Auto or Text - in text
       mode the bars come out grey/streaky and won't scan), and print darkness on NORMAL (not light). The page already prints
       the bars thinned to allow for thermal spread, so turning the darkness down as well makes them too faint.
- Chrome REMEMBERS print settings per profile and --kiosk-printing reuses them. If labels come out enlarged, cut off, or with a
  "1/1" page number on them, set them once: start the shortcut WITHOUT --kiosk-printing, press a line's printer icon, and in the
  dialog choose  Destination: the Dymo · Paper size: the 54 mm one (not 30252) · Margins: None · Scale: Default · More settings > Headers and footers OFF.
  Print, close Chrome, put --kiosk-printing back.
- Test: open AMZ Shipment, scan a shoe with an FNSKU (or press a line's printer icon) - one label should print with no dialog.
- For local dev use http://localhost:3000 instead of the vercel URL.



== ROYAL MAIL LABELS (Zebra) — Customer Orders scan-to-label

Scanning the last shoe of a customer order prints its Royal Mail label (a PDF from Click & Drop) with no dialog. Same idea as the
Dymo shortcut above, but its OWN shortcut and OWN Chrome profile, so it can point at the Zebra while the Dymo shortcut keeps the Dymo.

-- Shortcut target (paste into "Target"):

"C:\Program Files\Google\Chrome\Application\chrome.exe" --kiosk-printing --user-data-dir="C:\bcweb-chrome-zebra" https://bcweb.vercel.app/customer-orders

Name it e.g. "BCWEB (Royal Mail labels)".

-- One-time setup on each machine
1. Install the Zebra's Windows driver (zebra.com, "ZDesigner" driver for the model).
2. In the Zebra's Printing Preferences: paper/stock 4 x 6 in (101.6 x 152.4 mm), orientation PORTRAIT, and the media type that
   matches the roll (direct thermal labels, with gaps).
3. Click & Drop (one-off, account-wide, probably already set): Settings > label format = thermal 6 x 4 label, so the PDF's page is
   the label's size.
4. Set the Zebra as Chrome's printer for this profile:
     a. Start the shortcut WITHOUT --kiosk-printing (edit the Target, or run the same line without it) and log in to BCWEB.
     b. Print any page (Ctrl+P) and in the dialog choose  Destination: the Zebra · Paper size: 4 x 6 · Margins: None ·
        Scale: Default / Actual size (NOT "Fit to page") · More settings > Headers and footers OFF.
     c. Print, close Chrome, put --kiosk-printing back.
   Chrome remembers the last printer and settings per profile and kiosk printing reuses them — that's why the Zebra shortcut gets
   its own --user-data-dir. If this PC has NO other label printer you can instead just make the Zebra the Windows default printer.
5. Test: on Customer Orders scan the shoe of a single-pair order. One label should print, no dialog.

-- If it goes wrong
- Print dialog still appears: --kiosk-printing is missing, or another Chrome window with the same profile was already open (close
  ALL windows of this shortcut and start it again).
- Label goes to the Dymo / wrong printer: redo step 4 in THIS shortcut's window.
- Label shrunk, cut off or on two labels: the paper size or scale in step 4b, or the Zebra driver's stock size (step 2), isn't 4 x 6.
- Nothing prints and no error on screen: try it without --kiosk-printing to see what Chrome is doing.
