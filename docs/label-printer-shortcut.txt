== BCWEB label-printing Chrome shortcut (FNSKU labels on Goods In and AMZ Shipment)

Without this shortcut every label pops up Chrome's print dialog. With it, labels go straight to the default printer.

-- Shortcut target (paste into "Target" when creating the shortcut):

"C:\Program Files\Google\Chrome\Application\chrome.exe" --kiosk-printing --user-data-dir="C:\bcweb-chrome" https://bcweb.vercel.app

Name it e.g. "BCWEB (labels)".

-- Notes
- If Chrome is installed elsewhere, check the path: right-click your normal Chrome shortcut > Properties > Target.
  (Sometimes it is "C:\Program Files (x86)\Google\Chrome\Application\chrome.exe".)
- --user-data-dir gives this shortcut its own Chrome profile, so your normal Chrome keeps the print dialog. Log in to BCWEB once in it.
- Close ALL Chrome windows before first use if you leave --user-data-dir off, or the flag is ignored.
- --kiosk-printing sends EVERYTHING printed from this window to the Windows default printer, so:
    1. Install the label printer's Windows driver.
    2. Make the label printer the Windows default printer.
    3. In the Dymo's Printing Preferences set the paper to the label roll: a 54 mm long size to match the labels on the roll
       (25 x 54 mm - 11352 / 30336 "1 x 2-1/8 in"), orientation PORTRAIT. NOT 30252 Address: that's 89 mm long and the label
       prints ~17 mm along, cut off. The page is sent portrait with the label drawn sideways (the preview looks sideways - right).
    4. Still in the Dymo's Printing Preferences > Advanced: Print Quality = "Barcodes and Graphics" (NOT Auto or Text - in text
       mode the bars come out grey/streaky and won't scan), and print darkness on NORMAL (not light). The page already prints
       the bars thinned to allow for thermal spread, so turning the darkness down as well makes them too faint.
- Chrome REMEMBERS print settings per profile and --kiosk-printing reuses them. If labels come out enlarged, cut off, or with a
  "1/1" page number on them, set them once: start the shortcut WITHOUT --kiosk-printing, press a line's printer icon, and in the
  dialog choose  Destination: the Dymo · Paper size: the 54 mm one (not 30252) · Margins: None · Scale: Default · More settings > Headers and footers OFF.
  Print, close Chrome, put --kiosk-printing back.
- Test: open AMZ Shipment, scan a shoe with an FNSKU (or press a line's printer icon) - one label should print with no dialog.
- For local dev use http://localhost:3000 instead of the vercel URL.
